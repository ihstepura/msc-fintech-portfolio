# Source documents

The PDFs, cleaned text, chunks and vector database are not included in this repository. All source documents are publicly available from the official EU and UK sources below. They were downloaded by hand because EUR-Lex blocks automated access.

[`multi_reg_manifest.json`](multi_reg_manifest.json) records the metadata used for the NIS2, PS21/3 and cross-regulation documents.
